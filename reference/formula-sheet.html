Notation

The symbols used on this page. The glossary carries the same list with the words attached.

Population and sample

β1, β2 — unknown population parameters

β̂1, β̂2 — estimated from a sample

ui — the disturbance, unobservable  ·  ûi — the residual, computed

A hat means estimated. β2 is fixed and unknown; β̂2 is random, because it is a function of the sample.

Deviations from means

xi = Xi − X̄  ·  yi = Yi − Ȳ

Lower case always means a deviation. Every deviation-form result below can be written in raw sums instead, and usually is not, because it is longer.

Sizes

n — observations  ·  k — parameters estimated, including the intercept  ·  n − k — degrees of freedom

k counts the intercept. In the two-variable model k = 2 and the degrees of freedom are n − 2.

Sums of squares

TSS = Σyi2  ·  ESS = Σŷi2  ·  RSS = Σûi2

The model

Population regression function Unit 1B

E(Yi | Xi) = β1 + β2Xi

Yi = β1 + β2Xi + ui

The systematic part plus the disturbance. Regression estimates a conditional mean, not a value.

Sample regression function Unit 1B

Ŷi = β̂1 + β̂2Xi  ·  Yi = β̂1 + β̂2Xi + ûi

ûi = Yi − Ŷi

Multiple regression Unit 1D

Yi = β1 + β2X2i + β3X3i + ⋯ + βkXki + ui

β2 is the effect of X2 on Y holding the other regressors constant — a partial coefficient.

OLS in the two-variable model

What OLS minimises Unit 1B

min   Σûi2 = Σ(Yi − β̂1 − β̂2Xi)2

Squared, not absolute: it penalises large misses more heavily and is differentiable everywhere.

Normal equations Unit 1B

ΣYi = nβ̂1 + β̂2ΣXi

ΣYiXi = β̂1ΣXi + β̂2ΣXi2

The first-order conditions. Solving them gives the estimators below.

The estimators, deviation form Unit 1B

β̂2 = Σxiyi / Σxi2  ·  β̂1 = Ȳ − β̂2X̄

The form to memorise. Everything from Unit 1C on is built on it.

The estimators, raw sums Unit 1B

β̂2 = ( nΣXY − ΣXΣY ) / ( nΣX2 − (ΣX)2 )

β̂1 = ( ΣX2ΣY − ΣXΣXY ) / ( nΣX2 − (ΣX)2 )

The same estimators, in the sums a table of data hands you directly. Use these when the question gives ΣX, ΣY, ΣXY and ΣX2.

The OLS weights Unit 1C

ki = xi / Σxi2  ⟹  β̂2 = ΣkiYi

Σki = 0  ·  ΣkiXi = 1  ·  Σki2 = 1 / Σxi2

β̂2 is a linear function of Y — the L in BLUE. The three identities do the work in every proof that follows.

Algebraic properties of the fitted line Unit 1C

Σûi = 0  ·  ΣûiXi = 0  ·  the line passes through (X̄, Ȳ)

These hold by construction, whatever the data. They are consequences of including a constant, not evidence that the model is any good.

The classical assumptions

The seven of the classical linear regression model (CLRM), in the order Unit 1C numbers them. Unit 2 is a tour of what happens when each fails.

1 · Linear in parameters Unit 1C

Yi = β1 + β2Xi + ui

Linear in the βs. Non-linear in the variables is fine: X2, ln X and interactions all satisfy it.

2 · X fixed in repeated sampling

X is non-stochastic, or is treated as fixed across samples. What relaxing it costs is the subject of Unit 3B.

3 · Regressors uncorrelated with the disturbance

cov(Xi, ui) = 0

Fails ⟹ biased and inconsistent. The one failure a larger sample does not repair — Unit 3B.

4 · Zero conditional mean

E(ui | Xi) = E(ui) = 0

Guaranteed at the sample level by including a constant, which is why Unit 2A Part 2 says never to suppress it.

5 · Homoscedasticity

var(ui) = E(ui2) = σ2, the same for every i

Fails ⟹ still unbiased, no longer efficient, standard errors wrong — Unit 2C.

6 · No autocorrelation

cov(ui, uj) = E(uiuj) = 0   for i ≠ j

Fails ⟹ still unbiased, no longer efficient, standard errors wrong — Unit 2D.

7 · No perfect collinearity

No regressor may be an exact linear function of the others. Fails ⟹ the estimator does not exist at all — Unit 2B.

Normality — added, not one of the seven Unit 1E

ui ∼ N(0, σ2)  ·  equivalently ui ∼ NID(0, σ2)

CLRM + normality = CNLRM. Nothing already proved is lost; what is gained is the sampling distributions that make Unit 1F's tests possible.

Properties of the OLS estimators

Sampling error Unit 1C

β̂2 = β2 + Σkiui = β2 + Σxiui / Σxi2

The single most useful line in the course. Take expectations for unbiasedness, square for the variance, take probability limits for consistency.

Unbiasedness

E(β̂2) = β2 + ΣkiE(ui) = β2

Needs assumptions 2, 3 and 4 and nothing else — not homoscedasticity, not no-autocorrelation, not normality.

Variances and covariance Unit 1C

var(β̂2) = σ2 / Σxi2  ·  se(β̂2) = σ / √( Σxi2 )

var(β̂1) = σ2 ΣXi2 / ( n Σxi2 )

cov(β̂1, β̂2) = − X̄ · σ2 / Σxi2 = − X̄ · var(β̂2)

Precision rises with the spread of X, not with its level. A regressor that barely moves cannot identify a slope.

Estimating σ2 Unit 1C

σ̂2 = Σûi2 / (n − 2)   with   E(σ̂2) = σ2

Divide by n − k in general. The two lost degrees of freedom are the two coefficients the residuals were built from.

Gauss–Markov Unit 1C

var(β2*) = σ2Σ(wi − ki)2 + var(β̂2)  ≥  var(β̂2)

Under assumptions 1–7, OLS is BLUE — Best Linear Unbiased Estimator. Any other linear unbiased estimator differs by a sum of squares, which cannot be negative, and equals OLS only when wi = ki throughout.

Goodness of fit

The decomposition Unit 1C

Σyi2 = Σŷi2 + Σûi2  ⟹  TSS = ESS + RSS

Requires a constant in the model. The cross-product Σŷiûi vanishes only because Σû = ΣûiXi = 0.

Coefficient of determination

r2 = ESS/TSS = 1 − RSS/TSS = β̂22 Σxi2 / Σyi2

r2 = ( Σxiyi )2 / ( Σxi2 · Σyi2 )

0 ≤ r2 ≤ 1. It measures fit and nothing else — not correctness, not causation, not significance.

Multiple R2 Unit 1D

R2 = ( β̂2Σx2iyi + β̂3Σx3iyi ) / Σyi2

R2 never falls when a regressor is added, however useless the regressor. That is why it cannot be used to choose between models of different size.

Adjusted R2 Unit 1D

R̄2 = 1 − (1 − R2) · (n − 1) / (n − k)

R̄2 = 1 − [ RSS/(n − k) ] / [ TSS/(n − 1) ]

Charges for each parameter. It can fall when a variable is added, and it can go negative — which says the model is worse than predicting Ȳ every time.

Multiple regression

The three-variable model Y = β1 + β2X2 + β3X3 + u. Beyond three regressors the algebra is done in matrices and these forms are not asked for.

Normal equations Unit 1D

ΣYi = nβ̂1 + β̂2ΣX2i + β̂3ΣX3i

ΣYiX2i = β̂1ΣX2i + β̂2ΣX2i2 + β̂3ΣX2iX3i

ΣYiX3i = β̂1ΣX3i + β̂2ΣX2iX3i + β̂3ΣX3i2

The partial slopes Unit 1D

β̂2 = [ (Σx2iyi)(Σx3i2) − (Σx3iyi)(Σx2ix3i) ] / D

β̂3 = [ (Σx3iyi)(Σx2i2) − (Σx2iyi)(Σx2ix3i) ] / D

β̂1 = Ȳ − β̂2X̄2 − β̂3X̄3

D = (Σx2i2)(Σx3i2) − (Σx2ix3i)2

D is the common denominator, and it is what perfect collinearity drives to zero.

Variances Unit 1D

var(β̂2) = σ2Σx3i2 / D  ·  var(β̂3) = σ2Σx2i2 / D

cov(β̂2, β̂3) = − σ2Σx2ix3i / D

var(β̂j) = σ2 / [ Σxj2 ( 1 − Rj2 ) ]

The last form is the general one and the one to remember: Rj2 is from regressing Xj on all the other regressors. It reappears in Unit 2B as the VIF.

Degrees of freedom

σ̂2 = Σûi2 / (n − k)   — with three regressors, n − 3

Normality and maximum likelihood

Sampling distributions Unit 1E

β̂2 ∼ N( β2, σ2/Σxi2 )  ·  β̂1 ∼ N( β1, σ2ΣXi2/(nΣxi2) )

Z = ( β̂2 − β2 ) / σβ̂2 ∼ N(0, 1)

( n − 2 ) σ̂2 / σ2 ∼ χ2(n−2)

β̂ is a linear function of normal disturbances, so it is normal itself. This is where every test in Unit 1F comes from.

The likelihood Unit 1E

ln LF = − (n/2) ln σ2 − (n/2) ln(2π) − ½ Σ( Yi − β1 − β2Xi )2 / σ2

Maximising it in β1 and β2 is minimising the sum of squares, so ML and OLS give the same slope and intercept under normality.

Where ML and OLS differ

σ̃2 = (1/n) Σûi2  ·  E(σ̃2) = σ2 − (2/n)σ2

The ML variance estimator divides by n rather than n − 2, so it is biased downward in every finite sample but consistent — the standard example of the distinction.

Inference

Why t and not Z Unit 1F

( β̂j − βj ) / se(β̂j)  ∼  tn−k

σ is unknown, so se(β̂) uses σ̂ — an estimate in the denominator, which fattens the tails. With large n the t and the normal coincide.

Test statistic Unit 1F

t = ( estimate − hypothesised value ) / standard error = ( β̂j − bj ) / se(β̂j)

With bj = 0 this is the t-ratio printed by the software. For any other hypothesis you must compute it yourself.

Decision rules

two-tailed: reject if | t | > tα/2, n−k  ·  one-tailed: reject if t is beyond tα, n−k in the direction of H1

equivalently: reject if p < α

The two-tailed test is the default, because it does not assume the answer. Choose one tail only when theory rules the other out in advance.

Confidence interval Unit 1F

β̂j ± tα/2, n−k · se(β̂j)

A 95% interval contains every value of βj a two-tailed 5% test would fail to reject — so the interval and the test are the same statement.

A linear combination Unit 1F

se( β̂2 − β̂3 ) = √[ var(β̂2) + var(β̂3) − 2 cov(β̂2, β̂3) ]

se(β̂2 − β̂3) ≠ se(β̂2) − se(β̂3). The covariance term is compulsory, and it is why the variance–covariance matrix has to be asked for.

The F-test Unit 1F

F = [ (RSSR − RSSUR) / q ] / [ RSSUR / (n − k) ]  ∼  F(q, n − k)

F = [ (R2UR − R2R) / q ] / [ (1 − R2UR) / (n − k) ]

q is the number of restrictions, k the parameters in the unrestricted model. The R2 form works only when both models have the same dependent variable.

Overall significance Unit 2B

F = [ R2 / (k − 1) ] / [ (1 − R2) / (n − k) ]

Tests H0: every slope is zero. A large F with no significant t-ratios is the classic symptom of multicollinearity.

The one-restriction identity

F = t2   when q = 1

Functional forms

What the coefficient means depends entirely on which of these you estimated. State the form before interpreting a magnitude.

Linear (lin–lin) Unit 2A Part 2

Y = β1 + β2X + u  ⟹  β2 = ∂Y/∂X

A one-unit change in X changes Y by β2 units.

Double-log

ln Y = β1 + β2 ln X2 + β3 ln X3 + u

βk = (ΔY/Y) / (ΔXk/Xk) = the elasticity of Y with respect to Xk

Constant elasticity, read straight off the coefficient. The Cobb–Douglas Q = β1Lβ2Kβ3eu becomes linear in this form.

Log–lin (semi-log)

ln Y = β1 + β2X + u  ⟹  %ΔY per unit of X = 100[ eβ2 − 1 ]

100β2 is the usual approximation and is good for small β2. Use the exact form when β2 is large or the regressor is a dummy.

Lin–log

Y = β1 + β2 ln X + u,   X > 0

A 1% rise in X changes Y by about β2/100 units.

Quadratic and its turning point Unit 2A Part 2

Y = β1 + β2X + β3X2 + u  ⟹  ∂Y/∂X = β2 + 2β3X

X* = − β̂2 / 2β̂3

The partial effect depends on X, so it cannot be quoted as a single number. Check the turning point lies inside the range of the data before interpreting it.

Interaction term Unit 2A Part 2

Y = β1 + β2X2 + β3X3 + β4(X2·X3) + u

∂Y/∂X2 = β2 + β4X3

With the product term in the model, β2 is the effect of X2 when X3 = 0 — often a value nobody in the sample has.

Specification

Omitted variable bias Unit 2A Part 1

true: Y = β1 + β2X2 + β3X3 + u  ·  run: Y = β1* + β2*X2 + ε

E(β̂2*) = β2 + β3δ̃1,   δ̃1 = Σx2x3 / Σx22

Bias(β̂2*) = β3δ̃1

δ̃1 is the slope from regressing the omitted variable on the included one. Sign the bias by signing β3 and the correlation and multiplying. No bias if either is zero.

The direction of the bias

β3 > 0, corr(X2, X3) > 0  ⟹  upward  ·  signs opposite  ⟹  downward

The variance trade Unit 2A Part 1

underfitted: var(β̂2*) = σ2/Σx22  ·  correct: var(β̂2) = σ2 / [ Σx22(1 − R223) ]

Omitting a relevant variable gives a smaller variance and a biased estimate; including an irrelevant one keeps unbiasedness and inflates the variance by 1/(1 − R223). Bias is the worse trade.

Ramsey RESET Unit 2A Part 1

Yi = α1 + α2X2i + ⋯ + γ1Ŷi2 + γ2Ŷi3 + ui

H0: γ1 = γ2 = 0  — an F-test with q = 2, so F(2, n − k − 2)

Rejection says the model is inadequate. It does not say why, and never says which variable to add.

Model selection criteria Unit 2A Part 1

AIC = n · ln( RSS/n ) + 2v

SC = ln( RSS/n ) + ( v/n ) ln n

Smallest wins. v is the number of parameters. SC penalises size more heavily than AIC, so it picks smaller models.

Structural change

Chow test Unit 2A Part 2

F = [ ( RSSR − RSSUR ) / k ] / [ RSSUR / ( n2 + n3 − 2k ) ]

RSSUR = RSS2 + RSS3

RSSR is from the pooled regression; RSS2 and RSS3 from the two sub-periods. Assumes the same disturbance variance in both, which is worth checking first.

Test of equal variances Unit 2A Part 2

F = σ̂12 / σ̂22  ∼  F(n1−k), (n2−k),   with σ̂j2 = RSSj/(nj − k)

Put the larger variance on top so the statistic exceeds one.

Multicollinearity

Perfect collinearity Unit 2B

X3 = α1 + α2X2  ⟹  β̂2 = 0/0

The estimator does not exist. What the data can identify is the combination β̂2 + α2β̂3, not the two coefficients separately.

The inflated variance Unit 2B

var(β̂j) = σ2 / [ Σxj2( 1 − Rj2 ) ] = ( σ2 / Σxj2 ) · VIF(β̂j)

Variance inflation factor Unit 2B

VIF(β̂j) = 1 / ( 1 − Rj2 )

Rj2 comes from the auxiliary regression of Xj on all the other regressors. Rj2 = 0.9 gives VIF = 10, the conventional alarm; the standard error is then √10 ≈ 3.2 times what it would otherwise be.

The symptom

A high R2 and a significant F, with few or no significant t-ratios. Estimates that swing when a variable is added or a few observations dropped. OLS remains BLUE throughout — multicollinearity is a shortage of information in the data, not a violation of an assumption.

Heteroscedasticity

The failure Unit 2C

var(ui) = σi2  — not constant across i

The true variance of β̂2 Unit 2C

var(β̂2) = Σxi2σi2 / ( Σxi2 )2

Set σi2 = σ2 and it collapses to σ2/Σxi2, which is what the software prints. So the printed standard error is wrong, and can be wrong in either direction. β̂2 itself stays unbiased.

Breusch–Pagan test Unit 2C

ûi2 = α1 + α2X2 + ⋯ + αkXk + ε

LM = nR2  ∼  χ2(d)

d is the number of slope terms in the auxiliary regression. R2 is the auxiliary's, not the original model's.

White test Unit 2C

ûi2 = α1 + α2X2 + α3X3 + α4X2X3 + α5X22 + α6X32 + ε

LM = nR2  ∼  χ2(d)

Squares and cross-products as well, so it catches forms Breusch–Pagan misses — at the cost of degrees of freedom. The economical variant uses Ŷ and Ŷ2 alone.

Weighted least squares Unit 2C

Yi/σi = β1/σi + β2X2i/σi + ui/σi

var(ui/σi) = σi2/σi2 = 1

Divide through by the standard deviation and the transformed disturbance is homoscedastic. Note the intercept is transformed too, and the equation now has no constant.

Feasible GLS Unit 2C

ln(ûi2) = α1 + δ2X2 + ⋯ + δkXk + e

σi is unknown, so estimate it. The exponential form keeps the fitted variance positive.

The four remedies

Re-examine the specification first — much heteroscedasticity is impure, caused by a missing variable or the wrong functional form. Then: log the data; use heteroscedasticity-corrected (White/robust) standard errors; weighted least squares; feasible GLS.

Autocorrelation

First-order scheme Unit 2D

ut = ρ ut−1 + εt,   | ρ | < 1,   ε well behaved

Moments of an AR(1) disturbance Unit 2D

var(ut) = σ2 = σε2 / ( 1 − ρ2 )

cov(ut, ut−s) = ρs σε2 / ( 1 − ρ2 )  ·  corr(ut, ut−s) = ρs

The memory decays geometrically and never quite ends. |ρ| < 1 is what keeps the variance finite.

The variance of β̂2 under AR(1) Unit 2D

var(β̂2)AR1 = ( σ2 / Σxt2 ) · [ 1 + 2ρ ( Σxtxt−1 / Σxt2 ) + 2ρ2 ( Σxtxt−2 / Σxt2 ) + ⋯ ]

The bracket depends on the regressor's own serial correlation as well as ρ. With both positive — the usual case in economic time series — the printed standard error understates the truth and t-ratios are inflated.

Durbin–Watson Unit 2D

DW = Σ( ût − ût−1 )2 / Σût2  ·  DW ≈ 2( 1 − ρ̂ )

0 ≤ DW ≤ 4. Near 2 is no autocorrelation; near 0 positive; near 4 negative. Two inconclusive zones between dL and dU. Invalid if the model contains a lagged dependent variable.

Breusch–Godfrey Unit 2D

ût on all the X's and ût−1, …, ût−q

( n − q )R2  ∼  χ2(q)

Tests to order q, has no inconclusive region, and survives a lagged dependent variable. The better test in every respect except familiarity.

The GLS transformation Unit 2D

Yt − ρYt−1 = β1(1 − ρ) + β2( Xt − ρXt−1 ) + εt

Quasi-differencing. The transformed disturbance ε is well behaved, so OLS on the starred variables is BLUE. ρ is unknown, so estimate it from ût = ρ̂ût−1 + vt and iterate — Cochrane–Orcutt, or Prais–Winsten, which keeps the first observation.

Newey–West

HAC standard errors: leave the coefficients alone and correct the standard errors for both autocorrelation and heteroscedasticity. A large-sample remedy, and the usual first move.

Dummy variables

A single dummy Unit 3A

Yi = β1 + β2Di + ui  ⟹  β̂1 = Ȳ0,   β̂2 = Ȳ1 − Ȳ0

Exactly the group means. Its t-test is the difference-of-means test.

The m − 1 rule

A qualitative variable with m categories gets at most m − 1 dummies alongside a constant. All m plus a constant sum to the column of ones: perfect multicollinearity, assumption 7 failing — the dummy variable trap. Always state which category is the base; a table of dummy coefficients without it is uninterpretable.

With quantitative regressors Unit 3A

E(Y | X, D = 0) = β1 + β3X  ·  E(Y | X, D = 1) = (β1 + β2) + β3X

Two parallel lines. β2 is the differential intercept coefficient — a dummy on its own shifts the line, it cannot tilt it.

Logged dependent variable Unit 3A

exact percentage effect = 100[ eβ̂2 − 1 ]

100β̂2 approximates it and always understates a positive effect. A dummy moves a whole unit, which is where the approximation is most stretched: β̂ = 0.40 is 49.2%, not 40%.

Interacted dummy Unit 3A

Y = β1 + β2D + β3X + β5(D · X) + u

∂Y/∂X = β3 + β5D  ·  gap at X = β2 + β5X

Now the lines may differ in slope as well as level. β2 becomes the gap at X = 0.

Do two groups share a regression? Unit 3A

H0: the dummy and all its interactions are zero  — an F-test

RSSUR = RSS1 + RSS2

The fully interacted regression is the two separate regressions run at once, so the identity holds and the F is exactly the Chow statistic. The single-equation form has the advantage that you can test which part differs.

Endogeneity

The failure Unit 3B

cov(Xi, ui) ≠ 0  ⟹  X is endogenous

Three sources: omitted variables, measurement error, simultaneity.

What OLS converges on Unit 3B

plim(β̂2) = β2 + cov(X, u) / var(X)

Biased and inconsistent: the second term is a constant, so it does not shrink with n. Unlike heteroscedasticity and autocorrelation, this is not repaired by more data.

Simultaneous system Unit 3B

Ct = β1 + β2Yt + ut  ·  Yt = Ct + It

Endogenous: determined inside the system. Exogenous: outside it. Predetermined: exogenous or lagged endogenous. Which side of the equals sign a variable sits on proves nothing.

The reduced form Unit 3B

Yt = β1/(1 − β2) + [1/(1 − β2)] It + [1/(1 − β2)] ut

Ct = β1/(1 − β2) + [β2/(1 − β2)] It + [1/(1 − β2)] ut

Every endogenous variable in terms of predetermined variables only. Its regressors are therefore uncorrelated with the disturbance, so OLS on the reduced form is consistent. The π coefficients are the impact multipliers.

Simultaneity bias, exactly Unit 3B

cov(Yt, ut) = σ2 / ( 1 − β2 )  > 0   for 0 < β2 < 1

plim(β̂2) = β2 + [1/(1 − β2)]( σ2/σY2 ) = β2 + (1 − β2) σ2/( σ2 + σI2 )

The marginal propensity to consume is overestimated, and the size of the error is the share of income's variation that comes from the disturbance rather than from investment.

Regressing Q on P Unit 3B

plim(β̂) = (1 − w) b2 + w a2,   w = σe2/( σu2 + σe2 )

A variance-weighted average of the supply and demand slopes. A curve is traced out by the shifting of the other one: shift demand only and OLS returns the supply slope.

IV, 2SLS and identification

The two conditions Unit 3C

(1) cov(Z, u) = 0  — instrument exogeneity

(2) cov(Z, X) ≠ 0  — instrument relevance

Relevance is testable, by a t- or F-test in the first stage. Exogeneity is not — u is unobservable, so the case for it is an argument, not a statistic.

The IV estimator Unit 3C

β̂2IV = Σ(Zi − Z̄)(Yi − Ȳ) / Σ(Zi − Z̄)(Xi − X̄) = cov(Z, Y)/cov(Z, X)

plim(β̂2IV) = β2 + cov(Z, u)/cov(Z, X) = β2

Consistent, but biased in small samples — it is a ratio, and the expectation of a ratio is not the ratio of expectations. Set Z = X and it is OLS.

The variance cost Unit 3C

var(β̂2IV) = σ̂2 / [ Σ(Xi − X̄)2 · r2X,Z ]

var(β̂2IV) / var(β̂2OLS) = 1 / r2X,Z  ≥  1

IV is always less precise, by exactly the reciprocal of the first-stage R2. Only the part of X the instrument accounts for is used.

Weak instruments Unit 3C

Three failures at once: the variance blows up; the finite-sample bias grows and points back towards OLS; and the asymptotic standard error understates the true spread. An instrument with no correlation at all reproduces OLS exactly. Look for a first-stage F of at least 10 before believing an IV estimate.

2SLS Unit 3C

stage 1: Xi = π1 + π2Ti + π3Zi + εi  ⟹  keep X̂i

stage 2: Yi = β1 + β2X̂i + β3Ti + ui

Every exogenous variable of the structural equation goes into stage 1 as well. With one instrument, 2SLS is IV. Never run the second stage by hand: the coefficients come out right and the standard errors do not.

In a simultaneous system Unit 3C

Every predetermined variable in the system is a candidate instrument, and the reduced form of a right-hand-side endogenous variable is the first stage. Substitute the fitted values on the right-hand side only.

Order condition Unit 3C

an equation must exclude at least M − 1 of the model's variables

exactly M − 1 → just identified  ·  more → overidentified  ·  fewer → underidentified

M is the number of endogenous variables. Equivalently: the predetermined variables in the system must be at least as many as the slope coefficients in the equation. Necessary, not sufficient. Work both statements and check they agree.

Rank condition Unit 3C

Necessary and sufficient. In a two-equation system: at least one exogenous variable excluded from the first equation must have a non-zero coefficient in the second. This is instrument relevance under another name — an equation can pass the counting and still be unidentified.

Indirect least squares Unit 3C

Estimate the reduced form by OLS and solve back for the structural parameters. Works only on a just identified equation, where it agrees exactly with 2SLS. On an overidentified one the solutions disagree and nothing says which to keep — which is why 2SLS is the standard method.

Which test, at a glance

Every test in the course, with the statistic and the distribution to compare it against.

Is one coefficient zero? Unit 1F
