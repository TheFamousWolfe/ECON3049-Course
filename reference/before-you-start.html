Before you start

The mathematics this course assumes, and where each piece is used.

How to use this You have met all of this already, in ECON 2025 and ECON 2026. It is gathered here so that you do not have to go looking for it in the middle of a derivation. Every row says where the course uses it, so you can see what each piece buys you rather than treating it as a hurdle. This sheet states results; it does not teach them. If a row is genuinely unfamiliar rather than merely rusty, your Statistical Methods notes are the place to go — not this page. Summation

The operator

Σi=1n Xi = X1 + X2 + ⋯ + Xn

Where the range is obvious the limits are dropped, and this course drops them almost always: ΣXi means the sum over the whole sample.

The three rules

Σ(Xi + Yi) = ΣXi + ΣYi

ΣcXi = cΣXi  ·  Σi=1n c = nc

c is a constant. The third rule is the one most often forgotten: summing a constant n times gives nc, not c.

Means and deviations

X̄ = (1/n)ΣXi  ·  xi = Xi − X̄

Σxi = Σ(Xi − X̄) = 0

Deviations from the mean always sum to zero. This single fact does most of the work in the OLS derivation, and it is why the normal equations simplify as far as they do.

Two identities worth knowing cold

Σxiyi = ΣXiYi − nX̄Ȳ

Σxi2 = ΣXi2 − nX̄2

They convert between deviation form and raw sums, which is what you need when a question gives you ΣXiYi and ΣXi2 and asks for a slope.

Where the course uses it

Unit 1B derives β̂2 = Σxiyi / Σxi2 entirely in this notation, and you will be asked to reproduce that derivation. Every sum of squares in Unit 1C — TSS, ESS and RSS — is a Σ.

Expectation

What it is

E(X) = Σ X p(X)

The probability-weighted average of the values a random variable can take — its long-run mean, not the mean of any particular sample.

Its algebra

E(c) = c  ·  E(cX) = cE(X)

E(X + Y) = E(X) + E(Y)

E(ΣaiXi) = ΣaiE(Xi)

The second line holds whether or not X and Y are independent. Expectation passes straight through sums and constants — which is precisely why it is the tool used to show an estimator is unbiased.

Conditional expectation

E(Y | X) — the mean of Y among observations sharing that value of X

Not an extra topic but the central one: a regression estimates a conditional mean, and the population regression function is E(Y | X).

Where the course uses it

The population regression function in Unit 1B is written E(Yi | Xi) = β1 + β2Xi. Assumption 3 is E(ui | Xi) = 0. Every proof in Unit 1C and Unit 1D that an estimator is correct on average is an exercise in the algebra above.

Variance and covariance

Variance

var(X) = E[(X − E(X))2] = E(X2) − [E(X)]2

var(c) = 0  ·  var(cX) = c2 var(X)

The constant comes out squared. Dropping the square is the single most common slip in a variance derivation, and it produces a standard error that is wrong by a factor of c.

Covariance

cov(X, Y) = E[(X − E(X))(Y − E(Y))] = E(XY) − E(X)E(Y)

cov(X, X) = var(X)  ·  cov(c, X) = 0

Covariance has units — the product of the units of X and Y — so its size on its own says nothing. That is what the correlation coefficient is for.

Variance of a sum

var(X + Y) = var(X) + var(Y) + 2cov(X, Y)

The cross term vanishes only when the covariance is zero. Much of Unit 2 is about what happens when a course of action assumes it away and it is not in fact zero.

Independence and correlation

X, Y independent ⟹ cov(X, Y) = 0

corr(X, Y) = cov(X, Y) / (σX σY),   −1 ≤ corr ≤ 1

The implication runs one way only. Zero covariance does not establish independence: it rules out a linear relation, and nothing more.

Where the course uses it

Two of the classical assumptions are statements in this notation — homoscedasticity is var(ui) = σ2 for every i, and no autocorrelation is cov(ui, uj) = 0 for i ≠ j. Unit 2C is what follows when the first fails and Unit 2D when the second does. The variance of β̂2 in Unit 1C is derived with the rules above and nothing else.

Differentiation

The rules you need

d(xn)/dx = n xn−1  ·  d(ln x)/dx = 1/x  ·  d(ex)/dx = ex

chain rule:   d f(g(x))/dx = f′(g(x)) · g′(x)

Nothing beyond this is required. The course never asks you to integrate.

Partial derivatives

∂f/∂x — differentiate with respect to x, treating every other variable as a constant

Written with ∂ rather than d purely to signal that the function has more than one argument.

Finding a minimum

set ∂f/∂x = 0 for each argument in turn, then solve the resulting equations together

These are the first-order conditions. A positive second derivative confirms a minimum rather than a maximum; in this course the functions are well behaved and the check is rarely laboured.

Where the course uses it

This is how ordinary least squares is derived. Unit 1B minimises Σûi2 by taking the partial derivatives with respect to β̂1 and β̂2, setting both to zero, and solving the pair — those two equations are the normal equations. Unit 1E maximises a log-likelihood by exactly the same method.

Logarithms and exponentials

The rules

ln(ab) = ln a + ln b  ·  ln(a/b) = ln a − ln b

ln(ab) = b ln a  ·  ln 1 = 0  ·  ln e = 1  ·  eln x = x

ln always means the natural logarithm, to base e. This course uses no other base.

Where it is undefined

ln x exists only for x > 0

Not a technicality. It is why logging the data is not always available as a remedy — a variable containing zeros, negative values or percentages cannot simply be logged.

Logs and proportional change

for small r,   ln(1 + r) ≈ r

a change of 0.01 in ln Y ≈ a change of 1 per cent in Y

This approximation is the reason a coefficient in a logged model reads as a percentage, and the reason that reading is approximate. It degrades as the change grows, which is why the exact form is preferred for anything large.

Where the course uses it

Unit 2A Part 2 is built on this section. Taking logs is what makes a Cobb–Douglas production function linear in the parameters, and the four functional forms — linear, double-log, log-lin and lin-log — differ only in which side has been logged. The exact semi-elasticity 100(eβ̂ − 1) comes straight from the rules above.

Matrix algebra

Shapes

an m × n matrix has m rows and n columns  ·  a vector is a matrix with one row or one column

A matrix is square when m = n, and symmetric when it equals its own transpose.

Multiplication and conformability

AB is defined only when the columns of A equal the rows of B

(m × n)(n × p) = (m × p)

Order matters: AB and BA are different products, and one may not exist at all.

Transpose

A′ — rows become columns  ·  (AB)′ = B′A′

X′X is the cross-product matrix of the regressors. It is square and symmetric whatever shape X has.

Identity and inverse

AI = IA = A  ·  AA−1 = A−1A = I

The inverse is the matrix analogue of dividing. It exists only if A is square and non-singular.

When the inverse fails

A singular  ⟺  determinant of A = 0  ⟺  its columns are linearly dependent

rank — the number of linearly independent columns

One column being an exact linear combination of the others is enough. The three statements are the same statement.

Where the course uses it

The row above is perfect multicollinearity. In Unit 2B a regressor that is an exact linear combination of the others makes the columns of X linearly dependent, so X′X is singular, cannot be inverted, and the estimator does not exist — which is why the software returns an error rather than a number. Unit 1F reads the variance–covariance matrix of the estimates, with the variances on the diagonal and the covariances off it. Unit 3C states the rank condition for identification.

The four distributions

Normal

X ∼ N(μ, σ2)  ·  Z = (X − μ)/σ ∼ N(0, 1)

Symmetric about μ, and fully described by its mean and variance. Standardising subtracts the mean and divides by the standard deviation.

Chi-square

the sum of v independent squared standard normals ∼ χ2(v)

Non-negative and skewed to the right, with one degrees-of-freedom parameter. Because it is built from squares, tests based on it are right-tailed: departures in either direction make the statistic larger.

t

t(v) = Z / √(χ2(v)/v)

A standard normal divided by the square root of an independent chi-square over its degrees of freedom. Symmetric like the normal but with fatter tails, because the denominator is estimated rather than known; it approaches the normal as v grows.

F

F(v1, v2) = [χ2(v1)/v1] / [χ2(v2)/v2]

The ratio of two independent chi-squares, each divided by its own degrees of freedom — hence two df parameters, and hence a table that needs two entries to read.

Where the course uses it

Each one carries a specific job. The t tests a single coefficient in Unit 1F; the F tests several restrictions at once there, and reappears as the Chow and RESET tests in Unit 2A. The chi-square carries every LM test in Unit 2 — Breusch–Pagan, White and Breusch–Godfrey are all nR2 against a χ2. Knowing that t is built from a normal over a chi-square is what explains why it is the t and not the normal that appears once σ2 has to be estimated.

The vocabulary of testing

Population and sample

a parameter describes the population  ·  a statistic is computed from a sample

A parameter is fixed and unknown. A statistic is known and random, because a different sample would have given a different value.

Sampling distribution

the distribution of a statistic across repeated samples

standard error — the standard deviation of that distribution

A standard error is not a property of your data; it is a property of the procedure that produced the estimate. Every test in this course is a statement about a sampling distribution.

The two hypotheses

H0 — the null, the claim under test  ·  H1 — the alternative

The null is what the arithmetic assumes while the statistic is computed. One-tailed or two-tailed is a property of the alternative, decided before you look at the data.

Making the decision

significance level α  ·  critical value  ·  rejection region

p-value — the probability of a statistic at least as extreme as the one observed, if H0 is true

The p-value is a probability about the statistic, never about the hypothesis. Failing to reject is not the same as accepting: it means the data did not supply enough evidence, which is a statement about the sample as much as about the world.

The two errors

Type I — rejecting a true H0, with probability α

Type II — failing to reject a false H0

Choosing α fixes the first directly and the second only indirectly. Lowering α to be cautious about one error makes the other more likely.

Confidence intervals

estimate ± (critical value × standard error)

The interval is random and the parameter is fixed, so the confidence attaches to the procedure across repeated samples, not to the one interval in front of you.

Where the course uses it

Unit 1F applies all of it to regression coefficients, and the whole of Unit 2 assumes it: every diagnostic there reports a statistic, a distribution, a critical value and a decision, in that order. The examination expects the same five steps every time — null, alternative, statistic, critical value, and a conclusion in words.
