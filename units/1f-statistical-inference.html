Statistical Inference and Hypothesis Testing

t-tests, confidence intervals and F-tests — deciding what the data will support.

By the end of this unit you should be able to
  • explain why the t-distribution replaces the normal once σ is estimated;
  • set out a hypothesis test in full, and say why the null must contain an equality;
  • carry out one-tailed and two-tailed t-tests and state the decision rule for each;
  • test a hypothesis that a coefficient equals a value other than zero;
  • construct and interpret a confidence interval, and use it to conduct a test;
  • test a linear combination of two coefficients, using the variance–covariance matrix;
  • test joint significance with an F-test, by either the RSS or the R2 formula;
  • use p-values, and read the output of a regression package.
Back to basics In this unit we return to the essence of econometrics: the effort to quantify economic relationships by analysing sample data — and the question of what conclusions we can draw from that quantification. Economic theory suggests that certain coefficients should take particular values. In the consumption function C = β1 + β2Y + u, theory says β2 > 0. Hypothesis testing is how we find out whether the relationships suggested by theory are upheld by the data to hand.

1 · What the sample can and cannot settle

Consider an estimated equation for years of education:

EDUĈ = 7.779 + 0.278 MOTHEDUC + 0.189 FATHEDUC − 0.161 SIBS

The estimated coefficients are specific to the sample used. How reliable are they? Are the observed estimates the product of chance, or is the sample estimate actually in line with theory? The information in the coefficients and their standard errors is what lets us decide.

What a test can never do The sample is used to make inferences about the population, but we can never really prove that a theory is "correct" with hypothesis testing. A test either finds enough evidence to reject a stated position or it does not. This is why most economists say "do not reject" rather than "accept" the null — and it is worth reading Wooldridge section 4.2 for the argument.

2 · Why t, and not Z

The whole procedure rests on Unit 1E. We need the normality assumption

ui ~ N(0, σ2)

and, provided the other classical assumptions hold, each estimated coefficient is normally distributed around its own true value:

β̂j ~ N( βj, var(β̂j) )

Standardising in the usual way — subtract the mean, divide by the standard deviation — gives a standard normal:

( β̂j − βj ) / σβ̂j ~ N(0, 1)  where  σβ̂j = √var(β̂j)

There is one problem, and it is the same problem as in Units 1C and 1D. var(β̂j) requires σ2, the variance of the disturbance, which cannot be observed. We replace it with the estimate σ̂2 built from the residuals, and the resulting estimate of the standard deviation of β̂j is what we call the standard error, se(β̂j). Making that substitution costs us the normal distribution:

The result the whole unit uses

( β̂j − βj ) / se(β̂j) ~ tn−k = tdf

Because the denominator is estimated rather than known, the standard normal is replaced by the t-distribution with n − k degrees of freedom, k being the number of parameters including the intercept. The extra uncertainty in σ̂ is what makes the tails of the t fatter than the normal's — and it is why critical values are larger in small samples. As n grows, t → Z.
n − k or n − k − 1? This course follows Gujarati: k counts all parameters including the intercept, so the degrees of freedom are n − k. Wooldridge counts k slopes and writes n − k − 1. The two give the same number for the same model. Decide which convention you are using before you open the tables, and say so in your answer.

3 · Setting out a test

Hypothesis testing in a regression resembles the steps from Introductory Statistics and Statistical Methods II. State the hypothesis to be tested, then formulate it algebraically as a null and an alternative.

As a rule, there must always be some form of equality in the null
Two-tailedLeft-tailedRight-tailed
Null H0== or ≥= or ≤
Alternative H1≠<>
Gujarati uses ≤ or ≥ in the null for one-tailed tests; Wooldridge sticks to "=". Either is acceptable, provided the alternative is its strict complement.

The reason the null carries the equality is practical: the null is the hypothesis you compute under. "β2 = 0" gives a specific number to build a test statistic around; "β2 ≠ 0" does not.

The test statistic

The t-test — or t-ratio — takes the estimate, subtracts the value the null asserts, and expresses the gap in units of the estimate's own imprecision:

tβ̂j = ( β̂j − βj ) / se(β̂j)

If the estimated coefficient is close to the value stated in the null, the hypothesis is not rejected. If it is far from it, the hypothesis is rejected. The standard error is what defines "far": a gap of 0.5 is enormous if the standard error is 0.05 and negligible if it is 2.

Hypotheses are about β, never about β̂ The hypothesis is always stated in terms of the population parameters βj — never the regression estimates β̂j. Why? Because β̂j is a number you already have; there is nothing to test about it. The unknown is the population parameter, and the estimate is the evidence being brought to bear on it.

4 · The decision rules

Compare the calculated t to the critical value from the t-tables, at n − k degrees of freedom and a significance level α — where α is the probability of rejecting H0 when H0 is true.

two Two-tailed (H1: βj ≠ b). Reject if |tβ̂j| > crit, using α/2 in each tail. Otherwise do not reject.
left Left-tailed (H1 contains "<"). No absolute values here: reject if tβ̂j < −crit, making the tabulated value negative.
right Right-tailed (H1 contains ">"). Reject if tβ̂j > crit, using the value exactly as it appears in the table.

One-tailed tests, in this course A one-tailed test puts the whole of α into a single tail, which lowers the critical value and makes rejection easier. That is legitimate only if the direction was chosen before looking at the estimate. In practice, one-sided alternatives are rarely used, and they should be used only where there is a clear reason from economic theory, prior empirical evidence, or both. In this course, use a one-tailed test only if explicitly asked to.

5 · Worked example: one-tailed tests

Consider a model of the demand for a normal good over time:

Dt = β1 + β2Pricet + β3Incomet + ut

A-priori expectations. Economic theory says that for a normal good, demand falls as price rises and rises as income rises: β2 < 0 and β3 > 0. Stating those before estimating is what entitles us to a one-tailed test here.

Monthly data for the last 200 months gives:

D̂t =s.e.t = 2.102(0.911)2.308 − 0.356 Pricet(0.110)−3.236 + 0.521 Incomet(0.213)2.446 n = 200  ·  k = 3  ·  df = 197

Own price — a left-tailed test

  1. H0: β2 = 0  ·  H1: β2 < 0. The null says own price has zero impact once income is accounted for. The alternative says the relationship is the negative one theory predicts.
  2. α = 0.05. If no significance level is given, always default to 5%.
  3. Test statistic and critical value:

    tβ̂2 = ( −0.356 − 0 ) / 0.110 = −3.236

    crit = tα, n−k = t0.05, 197 ≈ 1.645

  4. Decision: tβ̂2 < −crit, since −3.236 < −1.645. Reject the null that β2 = 0.
  5. Conclusion: the evidence suggests that the partial effect of own price on demand for this good is negative and statistically significant, ceteris paribus.

Income — a right-tailed test

  1. H0: β3 = 0  ·  H1: β3 > 0, having been explicitly asked to test one-sided.
  2. Test statistic and critical value, α = 0.05 as before:

    tβ̂3 = ( 0.521 − 0 ) / 0.213 = 2.446  ·  crit = t0.05, 197 ≈ 1.645

  3. Decision: tβ̂3 > crit, since 2.446 > 1.645 — right tail, so the critical value stays positive. Reject the null.
  4. Conclusion: the results are in line with economic theory. There is a positive and statistically significant relationship between income and demand for this good, holding own price fixed.

6 · Why the two-tailed test is the default

We began by assuming the good was normal, and that assumption drove the hypotheses. But biscuits may not be a normal good — they could be inferior, in which case the signs differ. More often than not, economic theory admits more than one sign for a coefficient, or common sense says it could go either way. So we usually test

H0: βj = 0  ·  H1: βj ≠ 0

which says either the variable has no effect, or it has an effect that could be positive or negative. Note that you may have clear a-priori expectations and still use a two-tailed test — and in this course that is the default.

Wooldridge's argument, which is the real reason "At minimum, using a two-sided alternative prevents us from looking at the estimated equation and then basing the alternative on whether β̂j is positive or negative."
We should never use our regression estimates to help inform our hypothesis. We should have a hypothesis, and then use the data to test it. Choosing the tail after seeing the sign is not a slightly weaker procedure; it invalidates the stated α altogether.

7 · Worked example: two-tailed tests

A model of labour supply in Jamaica, estimating hours worked as a function of education in years of schooling and age in years, on 1,438 observations. Use α = 0.01:

hourŝ =s.e.t = 0.836(0.373)2.241 + 0.161 Education(0.025)6.440 + 0.001 Age(0.005)0.200 n = 1,438  ·  k = 3  ·  df = 1,435  ·  α = 0.01

Education

H0: β2 = 0 against H1: β2 ≠ 0.

tβ̂2 = ( 0.161 − 0 ) / 0.025 = 6.440  ·  crit = tα/2, n−k = t0.005, 1435 ≈ 2.576

Decision: |tβ̂2| > crit, so reject the null. Conclusion: the evidence suggests a statistically significant relationship between education and labour supply in Jamaica at the 1% level. The sign is positive, so more education is associated with more hours worked, ceteris paribus.

Age

H0: β3 = 0 against H1: β3 ≠ 0.

tβ̂3 = 0.001 / 0.005 = 0.200  ·  crit ≈ 2.576

Decision: |tβ̂3| < crit, so we do not reject the null. Conclusion: age has a statistically insignificant impact on labour supply, ceteris paribus, at the 1% level; there is no evidence of a relationship between age and hours worked in Jamaica.

Notice what the second conclusion does not say It says nothing about the sign. We are less concerned about signs when we find statistical insignificance — a coefficient we cannot distinguish from zero has no direction worth reporting. Writing "age has a small positive effect, though insignificant" is a common and costly error.

8 · Statistical significance is not importance

If a variable is statistically significant, go on to discuss the magnitude of the coefficient, to get a sense of its economic or practical importance. The two are different questions, and a large sample can make a trivial effect significant.

wageŝ =s.e.t = 1000(256.2)3.903 + 0.002 Education(0.001)2.000 + 0.061 Experience(0.025)2.440 wages in dollars  ·  education and experience in years

The coefficient on education is statistically significant at the 5% level. It is also two-tenths of a cent per year of schooling. No policy follows from that, and no student should choose a degree on the strength of it. Significance and importance are separate findings, and a good answer reports both.

And if the sign is wrong If a variable is statistically significant and practically important but carries the "wrong" sign, you must search for a plausible explanation of why it is contrary to the literature. Without one, a reader will reasonably suspect the model is misspecified — which is where Unit 2A begins.

9 · Testing a value other than zero

Nothing about the procedure requires the hypothesised value to be zero. Economic theory may imply a specific number b:

H0: βj = bj  ⟹  tβ̂j = ( estimate − hypothesised value ) / standard error = ( β̂j − bj ) / se(β̂j)

Suppose we want to test whether there is a one-to-one relationship between income and consumption — if income rises by $1, consumption rises by $1. For C = β1 + β2Y + u, the null is H0: β2 = 1.

Ĉ =s.e.t = 100(50.123)1.995 + 0.891 Y(0.214)4.164 n = 31  ·  k = 2  ·  R2 = 0.578

The estimate 0.891 looks different from 1 — but is it statistically different from 1? Testing H0: β2 = 1 against H1: β2 ≠ 1:

tβ̂2 = ( 0.891 − 1 ) / 0.214 = −0.509

Decision: the null cannot be rejected at the 1%, 5% or 10% level. Note the contrast with the t of 4.164 printed in the display: the same coefficient is comfortably distinguishable from zero and entirely indistinguishable from one. The t-statistic a package prints is always for a null of zero, and that is often not the interesting null.

10 · Confidence intervals

A confidence interval around a parameter gives a range of values the true population parameter can reasonably be expected to take. With (1 − α) percent confidence:

β̂j ± C · se(β̂j)

where C is the critical value corresponding to a two-tailed test at the α level.

Worked, on the consumption model

A 95% interval for β2, with n = 31 so n − k = 29:

C = t0.05/2, 29 = 2.045

0.891 ± 2.045 (0.214) = (0.453, 1.329)

We are 95% confident that β2 lies between 0.453 and 1.329.

An interval is a test, and a test is an interval If the hypothesised value of βj is not in the interval, reject H0: βj = bj at the α level. If it is in the interval, do not reject.
Both earlier results follow immediately. Testing β2 = 0: zero is not in (0.453, 1.329), so reject at 5%. Testing β2 = 1: one is in the interval, so do not reject — which is precisely what t = −0.509 said.

Interactive figure — requires JavaScript. It draws a confidence interval from each of forty independent samples against the fixed true parameter, marking those that fail to cover it, with controls for the confidence level and for redrawing the samples.

What the width depends on — and the caveat The width of the interval depends on the value of α, the residual sum of squares, the sample size, and the variation of the independent variables around their means. Three of those four are the same levers on precision identified in Unit 1C, which is no coincidence: the interval is built from se(β̂j).
And confidence intervals are only as good as the assumptions underneath them. An interval computed from a heteroscedastic or autocorrelated model is the wrong width, and being confidently wrong is worse than being uncertain.

11 · Testing a linear combination of parameters

Sometimes the interesting hypothesis involves more than one coefficient at once. In the model Y = β1 + β2X2 + β3X3 + β4X4 + u we might want to test

H0: β2 = β3, i.e. β2 − β3 = 0  ·  or   H0: β2 + β3 = 1

The structure is the same as before:

t = ( linear combination of estimates − hypothesised value ) / ( standard error of the combination )

Worked example

Ŷ =s.e. 75.321(70.123) + 0.725 X2(0.104) − 0.278 X3(0.124) + 0.524 X4(0.145) n = 64  ·  k = 4  ·  R2 = 0.778

Test H0: β2 = 1 + β3 against H1: β2 ≠ 1 + β3. Rewrite it as a statement about a single combination — H0: β2 − β3 = 1 — and the statistic is

t = [ ( β̂2 − β̂3 ) − ( β2 − β3 ) ] / se( β̂2 − β̂3 ) = [ ( 0.725 − (−0.278) ) − 1 ] / se( β̂2 − β̂3 ) = 0.003 / se( β̂2 − β̂3 )

The standard error of a difference is not the difference of the standard errors

se( β̂2 − β̂3 ) ≠ se(β̂2) − se(β̂3)

se( β̂2 − β̂3 ) = √var( β̂2 − β̂3 ) = √[ var(β̂2) + var(β̂3) − 2 cov(β̂2, β̂3) ]

The covariance term is essential and is not printed in a standard regression table. It comes from the variance–covariance matrix, which has the variances on the diagonal and the covariances off it — in EViews, View → Covariance Matrix. For k = 4 the matrix is 4 × 4 and symmetric, so cov(β̂2, β̂3) appears in both off-diagonal positions.

Note the sign trap in this example: β̂3 is itself negative, so β̂2 − β̂3 = 0.725 − (−0.278) = 1.003, not 0.447. With the numerator only 0.003, this null will not be rejected unless the standard error of the combination is extraordinarily small.

12 · Joint significance and the F-test

Sometimes we want to test a null about several parameters simultaneously — a joint test. The commonest form is a set of exclusion restrictions. In

Y = β1 + β2X2 + β3X3 + β4X4 + β5X5 + u

we might ask whether β2, β3 and β4 are all zero:

H0: β2 = β3 = β4 = 0  ·  H1: β2 ≠ 0 or β3 ≠ 0 or β4 ≠ 0

The alternative contains "or" because it takes only one non-zero parameter to make the null false. In this course, joint significance is tested with the F-test.

The two formulas — use whichever the output gives you

Ftest = [ (RSSR − RSSUR) / q ] / [ RSSUR / (n − k) ]

Ftest = [ (R2UR − R2R) / q ] / [ (1 − R2UR) / (n − k) ]

UR is the unrestricted regression — the full model. R is the restricted one, re-estimated with the q restrictions imposed, which for exclusion restrictions simply means dropping those variables and running it again. k always comes from the unrestricted model.

The critical value is Fqn−k at the chosen α: q is the numerator degrees of freedom, being the number of restrictions, and n − k is the denominator degrees of freedom. Reject if Ftest > Fcrit, and do not reject otherwise.

The intuition Does the unrestricted model do a better job of explaining the variation in Y than the restricted one? Dropping variables can only make the fit worse, so RSSR ≥ RSSUR always; the question is whether it gets worse by enough to be worth the q parameters. If it does, we reject the null that the restrictions can be imposed.

Worked example

A researcher models wages as a function of education (EDUC), experience (EXPER), father's education (FATHEDUC), mother's education (MOTHEDUC) and number of siblings (SIBS), on n = 1,230 observations. From the unrestricted regression:

RSSUR = 85,013.30  ·  R2UR = 0.1614

To test whether MOTHEDUC and SIBS are jointly significant at α = 0.10 — H0: β5 = β6 = 0 against H1: β5 ≠ 0 or β6 ≠ 0 — re-run the model without those two variables:

RSSR = 85,125.77  ·  R2R = 0.1602

  1. Two restrictions, so q = 2. The unrestricted model has k = 6, so n − k = 1,224.
  2. From the F-tables, F21,224 at α = 0.10 gives crit = 2.30.
  3. The test statistic, by the RSS formula:

    Ftest = [ (85,125.77 − 85,013.30) / 2 ] / [ 85,013.30 / 1,224 ] = 56.235 / 69.455 = 0.809

  4. Decision: Ftest < Fcrit, so we do not reject the null. MOTHEDUC and SIBS are jointly insignificant.
The same test by the R2 formula

Ftest = [ (0.1614 − 0.1602) / 2 ] / [ (1 − 0.1614) / 1,224 ] = 0.0006 / 0.000685 ≈ 0.876

Slightly different from 0.809, but the same decision. The gap is rounding: the R2 values are quoted to four decimal places, and their difference — 0.0012 — has only two significant figures left in it. Prefer the RSS formula when both are available, and never report an F to three decimals that was computed from R2s rounded to four.

t and F are the same test when q = 1 H0: βj = 0 against H1: βj ≠ 0 can be run as an F-test with q = 1. It gives the same answer, because

Ftest = ( ttest )2  when there is one restriction

So a t of 2.446 corresponds to an F of 5.983. The F-test is the generalisation; the t-test is the case everyone runs by hand.

13 · p-values

So far we have used the critical-value approach: compute a statistic, compare it to the value from the table at a chosen α. The alternative is the p-value.

Definition The p-value for a test statistic is the probability of observing a test statistic that size or more extreme, if the null hypothesis is true. Equivalently, it is the smallest significance level at which the null would still be rejected.
A large p-value is evidence in favour of the null. A small one is evidence against it. The rule is: reject if p < α, do not reject otherwise — and it holds for t-tests, F-tests, chi-square tests alike.

Reading regression output

A software package estimating a regression reports, for each coefficient: the estimate, its standard error, its t-statistic, and the p-value associated with that t — along with a good deal else. Two habits are worth forming now:

i The default p-value is for a two-tailed test of H0: βj = 0. If your null is one-sided, halve it. If your null is βj = 1, the printed p-value is answering a different question entirely and must be recomputed.
ii Report the p-value alongside the decision, not instead of it. "p = 0.043, so we reject at the 5% level" tells the reader both what was found and how close it was; "significant" on its own does not.

14 · Tutorial

Draft questions, to be replaced by the tutorial sheet issued in class.

Explain why the test statistic follows a t-distribution rather than a standard normal. What exactly changes, and why does the difference shrink as n grows?
Show solution

Under normality, (β̂j − βj)/σβ̂j ~ N(0, 1) — but that uses the true standard deviation, which contains the unobservable σ2. In practice σ2 is replaced by σ̂2 = Σûi2/(n − k), giving se(β̂j) in the denominator instead.

What changes: the denominator is now itself a random variable rather than a constant. A normal numerator divided by the square root of an independent chi-square divided by its degrees of freedom is, by definition, a t. This is where the result from Unit 1E — that β̂ is distributed independently of σ̂2, and that (n − 2)σ̂2/σ2 is chi-square — earns its place.

Why it shrinks: the extra variability comes entirely from estimating σ. As n grows, σ̂2 becomes an ever more precise estimate of σ2, the denominator behaves more like a constant, and the t converges on the normal — t → Z as n → ∞. In practice the two are close by about df = 30 and nearly indistinguishable by df = 120, which is why large-sample work quotes 1.96 without apology.

Using the consumption model Ĉ = 100 + 0.891Y with se(β̂2) = 0.214 and n = 31, construct a 99% confidence interval for β2. Compare it with the 95% interval (0.453, 1.329) and say what you can and cannot conclude at each level.
Show solution

With n − k = 29 degrees of freedom, the two-tailed critical value at α = 0.01 is t0.005, 29 = 2.756. So

0.891 ± 2.756 (0.214) = 0.891 ± 0.590 = (0.301, 1.481)

Comparison. The 99% interval is wider — it must be, since buying more confidence means saying less. Both intervals exclude zero, so β2 = 0 is rejected at both the 5% and the 1% level. Both contain 1, so the hypothesis of a one-to-one relationship between income and consumption cannot be rejected at either level.

What cannot be concluded: that the marginal propensity to consume is 1. Failing to reject a null is not evidence for it — this interval is consistent with an MPC anywhere from 0.30 to 1.48, which is almost the whole economically plausible range. The honest reading is that with n = 31 and this much residual variation, the data simply cannot pin the MPC down.

A model of house prices is estimated with 5 regressors on 45 observations, giving R2 = 0.62. Dropping three of them gives R2 = 0.55. Test whether the three belong in the model at the 5% level, stating H0, H1, q, both degrees of freedom, and your conclusion.
Show solution

Hypotheses. Numbering the dropped coefficients β4, β5, β6: H0: β4 = β5 = β6 = 0 against H1: at least one of them is non-zero.

Degrees of freedom. q = 3 restrictions. The unrestricted model has 5 slopes plus an intercept, so k = 6 and n − k = 45 − 6 = 39.

Test statistic, by the R2 formula:

F = [ (0.62 − 0.55) / 3 ] / [ (1 − 0.62) / 39 ] = 0.02333 / 0.009744 = 2.394

Decision. The critical value F339 at α = 0.05 is approximately 2.85. Since 2.394 < 2.85, we do not reject the null: the three variables are jointly insignificant at the 5% level, and there is no strong evidence that they belong in the model.

Two remarks. The decision is fairly close, and at α = 0.10 (critical value about 2.23) it would reverse — which is worth saying rather than hiding. And joint insignificance is not the same as each being individually insignificant; the reverse situation, where each t is small but the F is large, is the classic symptom of multicollinearity in Unit 2B.

A researcher runs a regression, sees that β̂2 is positive, and then decides to test H0: β2 = 0 against H1: β2 > 0 at the 5% level "because a one-tailed test is more powerful". Explain what is wrong, and what the true size of their test is.
Show solution

What is wrong. The alternative was chosen after looking at the estimate. A one-tailed test at 5% is only a 5% test if the direction was fixed in advance; here the researcher would have tested the left tail had the sign come out negative, so their procedure rejects whenever |t| exceeds the one-tailed critical value in either direction.

The true size. That procedure has 5% in each tail, so its actual significance level is 10%, not 5% — twice the stated risk of a false rejection. This is exactly the practice Wooldridge's argument for defaulting to two-tailed tests is designed to prevent, and it is why this course requires an explicit instruction before a one-tailed test may be used.

What they should do: either fix the direction from theory before estimating and say so, or use the two-tailed test — where the same t would be compared against the larger critical value, which is the honest price of not having committed in advance.

In the model Y = β1 + β2X2 + β3X3 + u you are told var(β̂2) = 0.0100, var(β̂3) = 0.0064 and cov(β̂2, β̂3) = −0.0048. Test H0: β2 = β3 given β̂2 = 0.42 and β̂3 = 0.18, with n = 60. Explain why ignoring the covariance would mislead you.
Show solution

Rewrite the null as H0: β2 − β3 = 0. Then

var(β̂2 − β̂3) = 0.0100 + 0.0064 − 2(−0.0048) = 0.0260

se(β̂2 − β̂3) = √0.0260 = 0.1612

t = (0.42 − 0.18 − 0) / 0.1612 = 0.24 / 0.1612 = 1.489

With n − k = 57, the two-tailed 5% critical value is about 2.002. Since |1.489| < 2.002 we do not reject: the two partial effects are not significantly different from each other.

Why the covariance matters. It is negative here, and it enters with a minus sign, so −2(−0.0048) = +0.0096 adds to the variance — over a third of the total. Ignoring it would give var = 0.0164, se = 0.128, and t = 1.875, which is still short of 2.002 but much closer, and at the 10% level the two approaches would disagree. A negative covariance between two estimates means they tend to move in opposite directions across samples, which makes their difference more variable, not less — precisely the case where dropping the term flatters you.

15 · Check yourself

In a regression hypothesis test, the null hypothesis must always contain
Correct — the null is the hypothesis you compute under, so it must supply a specific number to build the statistic around.
The null needs an equality because it has to give you a value to subtract: t = (β̂j − βj)/se. "β2 ≠ 0" supplies no number. Hypotheses are also always about the population parameter β, never the estimate β̂.
In this course, a one-tailed test should be used only when
Correct — the two-tailed test is the default, and a one-tailed alternative must be justified from theory before the estimates are seen.
Choosing the tail after seeing the sign doubles the true size of the test: a "5%" test run that way rejects 10% of the time when the null is true. The direction must be fixed in advance, which in this course means being explicitly asked.
Wages rise by 0.002 dollars per year of education, with t = 2.0 on n = 1,000. This means
Correct — significance and importance are separate findings, and a large sample can make a trivial effect significant.
t = 2.0 clears the 5% critical value, so the null is rejected — the effect is statistically significant. But it is two-tenths of a cent per year of schooling. Always report the magnitude alongside the test.
An F-test of H0: β2 = β3 = 0 differs from two separate t-tests because it
Correct — and the two can disagree: small individual t-statistics alongside a large F is the classic signature of multicollinearity.
The F-test asks whether the restrictions can be imposed together, which is a different question from asking about each separately. When q = 1 the two coincide, with F = t², but with two or more restrictions they can and do disagree.
